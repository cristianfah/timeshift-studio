# TIMESHIFT_STUDIO

Real-time temporal video effects lab for AI filmmakers — slit-scan, time
displacement, block shuffle, temporal echo, RGB time split and scan sweep,
all running 100% client-side on WebGL2.

> Work in progress — full docs land with v0.1.

## Run

No build step:

```bash
npx serve .
# or just open index.html in a modern browser
```
